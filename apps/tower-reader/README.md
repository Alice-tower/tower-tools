# 静读

静读是面向 Windows 10/11 x64 的读书工具，支持本地 TXT、常见可重排 EPUB、PDF，以及内嵌微信读书网页版。本地书库、阅读记录及设置均保存在本机，本地阅读不访问互联网；微信读书页面需要联网和 WebView2 Runtime。程序自带 Java 与本地阅读组件。

当前版本 1.2.1：修复 EPUB 末尾空白或隐藏文字导致页数截断、封面相对路径与转义路径导入失败、移出失败后残留无效记录、移出后缓存未清理，以及重复启动多次激活窗口的问题。保留微信读书常驻页面、登录数据、本地阅读进度、分类和全屏功能。

## 开始阅读

从工具塔打开“静读”，或运行仓库构建后的 outputs/tools/dev.towertools.towerreader/TowerReader.exe。

复制到其他电脑时须复制整个便携目录，保留 runtime、app、third-party 与 third-party-sources。首次从源码构建需要联网下载依赖和上游源码，已交付程序的本地阅读不需要联网，微信读书需要联网。

- 把一个或多个 TXT、EPUB、PDF 文件拖入窗口，或点击本地书库左下角固定的“导入书籍”按钮多选文件。
- 导入会复制到静读管理的本地书库，保留用户的原文件。相同内容即使改名、换路径也不会重复加入；不同格式、不同版本不自动合并。
- 书卡显示封面、标题、格式，封面左上角显示“尚未阅读”或已读百分比。无封面时生成文字书卡。EPUB 优先使用内置封面，封面缺失或损坏时使用文字书卡；PDF 使用首页。
- 搜索匹配书名、作者和原文件名。分类为一级分类，右键书卡选择“编辑”，输入新名称或选择已有分类。
- 右键左侧具体分类，选择“编辑”修改分类名称；名称不能为空，也不能与另一分类重名。分类内所有书籍会一起更新，当前筛选与排序位置保留。
- 按住分类左侧的三横线手柄上下拖动，松开后保存顺序；靠近列表上下边缘时自动滚动。“全部书籍、最近阅读、未分类”固定在上方。已有分类首次升级沿用原名称排序，新分类放在末尾；分类中已无书籍时从列表消失。
- “最近阅读”按打开时间排列。点击封面或书名继续阅读。
- 右键书卡选择“移出”，确认后删除静读管理的副本、封面、该书正文/图片缓存及记录，原文件保留。数据库提交失败时保留文件；文件清理受阻时保留清理任务，下次启动重试。
- 大批量导入时可以取消后续文件；已成功导入的书仍保留。退出时也会请求取消剩余导入，等待当前文件操作结束并保存。

## 微信读书

- 点击顶部“微信读书”，首次打开 https://weread.qq.com/web/shelf，在网页内扫码登录。
- 切回本地书库不销毁网页，再次切入时回到原页面。隐藏网页后停止显示，并尝试挂起网页脚本以减少后台开销；因此后台听书不保证继续。
- 重开软件时恢复上次选择的模块；微信读书恢复上次的书架或阅读链接。登录跳转参数不写入导航记录。阅读位置与书架内容由微信读书网站管理。
- 登录所需 Cookie、网站存储与缓存保存在本机专用 profile 中，正常退出及更新程序不会主动清除。微信读书服务端要求重新验证时仍需扫码，不承诺永久免登录。
- 提供后退、前进、刷新、回书架、全屏。F11 进入/退出全屏，Esc 退出全屏；网页自己的方向键和输入框照常使用。
- “清除登录数据”需要确认，只清除微信读书的网站数据和缓存，本地书库与阅读记录保留。
- 关闭软件会关闭网页组件，不驻留托盘。使用系统已有 Microsoft Edge WebView2 Runtime；未安装时显示错误，不影响本地阅读。运行库可从微软官方 https://developer.microsoft.com/microsoft-edge/webview2/ 获取。
- 本地书库搜索、分类与微信读书书架分别管理；不导出网站书籍或合并在线阅读进度。本地阅读仍可完全离线。

## 阅读操作

| 操作 | 方法 |
| --- | --- |
| 翻页 | 左右方向键、Page Up / Page Down、底部按钮 |
| 空格翻页 | 空格下一页，Shift+空格上一页 |
| 全屏 | F11 或工具栏“全屏”；上下栏和底部提示全部隐藏，只保留书页 |
| 退出全屏 | F11 或 Esc |
| 返回书库 | “← 书库”，正文区域可按 Esc |
| 跳转 | 拖动底部整书进度条；PDF 点击“跳转页码”打开对话框输入原始页号，右下角显示当前页码 |
| 目录 | 打开工具栏“目录”；TXT 自动识章，EPUB 按阅读顺序显示，PDF 使用已有大纲 |
| 单双页 | 阅读设置选择单页、双页、自动；窄窗口会回退单页 |
| 外观 | 书库固定暖纸；阅读提供暖纸、深色，TXT/EPUB 可调字体、字号、行距和页边距 |
| PDF 缩放 | 100% 适合页面，最高 300%；大于视口时可滚动查看 |
| TXT 乱码 | 阅读设置中切换 UTF-8、GB18030 或 UTF-16LE；编码选择按书保存 |

TXT/EPUB 的页码随字号和窗口变化，显示为“本节页码”，底部百分比表示整本书的位置。长章节会分成阅读小节，切页到边界时自动进入相邻小节。PDF 保留原始页码。

阅读窗口中的正文、工具栏或进度条获得焦点时均可用左右键翻页，也支持长按连续翻页。打开设置、目录、错误提示或编辑 PDF 页码时暂不接管翻页键，避免影响输入。

文字进度保存为“阅读小节 + 文字位置”，图片占一个位置单位；字号、行距或窗口改变后，重新定位到含原位置的页面。PDF 保存页号。翻页后约 0.4 秒自动保存，切书、窗口失焦和正常关闭时补存；强制终止可能丢失最后一次尚未写入的进度。

PDF 页面颜色与界面主题分开控制。“页面变暗”会改变插图颜色，因此默认关闭。

## 本地格式范围

- TXT：自动处理 UTF-8/UTF-16 BOM、校验 UTF-8，回退 GB18030；支持手动选择编码。保留自然段，识别常见中文及英文数字章节标题。
- EPUB：支持 OPF/spine 阅读顺序、nav/NCX 章节名、段落、标题、强调、列表、基本表格和静态图片。使用阅读器排版；不保留所有作者 CSS、嵌入字体、脚本和多媒体。
- EPUB 封面支持普通图片及仅包裹一张本地图片的简单 SVG 容器；后者转换为静态图片，不执行 SVG。固定版式、DRM、复杂 SVG/MathML、动画图片及部分特殊图片格式不在首版支持范围。图片尺寸、条目大小和章节嵌套过大时会给出提示或拒绝打开；单 XHTML 章节上限 4 MiB、单资源 16 MiB、解压后总量 256 MiB。图片上限 8192 像素边长和 1600 万像素。
- EPUB 正文同一阅读小节内的文字链接可以定位；跨章节正文链接暂不跳转，请使用目录。分块可能把同一原章节分成多节。
- PDF：支持常规和扫描 PDF 的原版页面显示及本地目录。首版不提供 OCR、文字重排、标注编辑、密码输入或 DRM 解锁。
- 书库搜索只搜索书籍信息，不是全文检索。首版没有云同步、在线书源、朗读、批注或复杂标签管理。

## 本机数据

稳定 Application ID：dev.towertools.towerreader。

默认目录：%LOCALAPPDATA%\Alice-tower\TowerTools\dev.towertools.towerreader\

- library.sqlite：书名、分类及其顺序、原文件名、阅读记录和阅读设置。
- books/：托管书籍副本。
- covers/：封面缩略图。
- cache/：可重建的正文索引、图片及 JavaFX 原生库缓存。
- weread/profile/：微信读书的登录数据与网站缓存；weread/navigation.properties 保存上次模块和页面。
- logs/：诊断日志。

重新构建或替换程序目录不会覆盖这些数据。备份时关闭静读，复制整个数据目录；仅复制 EXE 不会带走书库。数据损坏时会显示错误，不以空书库覆盖已有数据库。

## 性能设计与验证

TXT 流式读取并按约 48K 字符建立小节，缓存重开只读索引和文件大小信息；EPUB 按小节显示。当前屏幕是优先任务，过期的打开、渲染和排版结果不会替换新请求。

TXT/EPUB 在同一本书内复用一个阅读区域和两个 WebView：一个显示当前章节，一个准备阅读方向上的相邻章节。新章节排版完成前保留当前页，命中预排页面时直接切换；正文片段缓存最多三个。窗口尺寸与字体变化会重新排版，预加载不会装入整本书。

阅读页面在后台写入本地临时 HTML，以便直接读取书库缓存中的图片；图片不转为整章内嵌数据。排版稳定后只保留两个页面文件，关闭阅读器时清理，均位于本机数据目录的 cache/pages/。

PDF 在独立串行工作线程按显示尺寸渲染，仅有限预读相邻页；输出图片 LRU 缓存最多 96 MiB，单张输出最多 16 Mi 像素。该限制不包含 PDFBox 解析文档及解码原始大图片所占的全部内存。书库仅为可见书卡加载缩略图，导入文件处理与数据库短操作分开。

测试包括真实 WebView 中文单/双页、字体和窗口重排、长插图与纯图片分页、数据库保存与失败保护、搜索分类和移出交互、32MB TXT、1000页合成 PDF、连续翻页与重排。报告见[验证记录](VERIFICATION.md)。自动重复测试不等价于数小时人工阅读或所有真实图书的兼容性测试。

## 构建

在仓库根目录：

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Tool.ps1 -Id dev.towertools.towerreader
~~~

使用 JDK 21，Gradle user home 由仓库脚本管理。脚本运行测试并发布到 outputs/，不要单独更改 GRADLE_USER_HOME。新增工具已经同步启动器目录；若修改工具身份或目录，继续遵守仓库生命周期流程。

应用内部使用 Compose Desktop 管理书库与窗口，JavaFX WebView 随包提供文字排版，PDFBox 渲染 PDF，SQLite 管理数据。createDistributable 会校验并携带 OpenJFX 上游完整源码及 SDK Java 源码，缓存位于 outputs/third-party-sources/tower-reader/；这些大包不提交 Git。

开发者可对实际便携运行时执行诊断，第二个参数必须是新的或空的测试目录。诊断创建隔离夹具和报告，不打开用户书库：

~~~powershell
.\outputs\tools\dev.towertools.towerreader\TowerReader.exe --verify-runtime C:\path\to\empty-test-directory
~~~

第三方组件和来源见[依赖核对](DEPENDENCIES.md)、[源码来源](SOURCES.md)及仓库根第三方声明。
