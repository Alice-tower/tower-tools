# 代理环境变量

查看并管理当前 Windows 用户的 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY` 和 `NO_PROXY` 环境变量。

功能：

- 一屏展示当前 Windows 用户的四项代理环境变量及其与已保存预设的差异；主窗口默认尺寸为 780 × 480。
- 使用“先调整、后保存”的流程。右下角的“保存更改”是写入环境变量的统一入口，没有改动时禁用。列表保留系统当前值，并显示拟保存的新值或“删除变量”；底部提示未保存的项数和操作结果。
- 列表上方的“使用全部预设”和“清空全部”只准备更改，不立即写入。“撤销全部”恢复本次读取时的值；返回原值的项目自动取消待保存标记。
- 点击变量行打开详情，可查看和复制完整的当前值、待保存值和预设值，并使用此项预设、清空此项或撤销此项。单项操作同样需要返回主界面保存。
- 首次使用时预设为空。通过右上角“编辑预设”填写必需的 `HTTP_PROXY`、`HTTPS_PROXY` 和 `ALL_PROXY`，`NO_PROXY` 可留空或用逗号分隔。保存预设只更新配置，不修改环境变量；已准备的待保存值保持原样，需要重新使用预设才会更新。
- 未完成必要预设配置前不能使用预设，但可以清空变量。配置完成后，未设置的 `NO_PROXY` 与空字符串预设在比较状态中视为一致；实际保存时仍区分“删除变量”和“保存空字符串”。预设按钮按待保存值的精确差异启用，因此空预设可以替换待删除状态，也可撤回原值为空字符串时的删除草稿。
- 保存只写入本次改动的项目，不改动其他变量。在保存前重新读取当前值，发现改动项被外部程序修改时停止写入，并展示原始值、最新值和待保存值。选择保留或放弃更改后刷新，再检查并决定是否保存。
- 保存清空全部的更改时会再次确认，取消确认会保留待保存内容。保存失败时尝试恢复所有已尝试修改的项目，并保留待保存内容供重试；回滚不完整时会尝试重新读取实际当前值，展示未确认恢复项目的保存前值与当前值。核对完成前暂不允许编辑或保存，关闭窗口也不会直接退出；如果读取失败，可重试读取或明确选择保留当前状态并退出。核对后继续编辑会保留尚需保存的更改，撤销草稿只恢复已读取的实际当前值，不会恢复系统中已写入的值。
- 有未保存内容时，刷新可选择保留更改、放弃更改或取消；关闭窗口可选择继续编辑或放弃更改并退出。草稿只保存在本次运行的内存中。
- 保存成功后提示重启需要使用新配置的程序。已经运行的程序通常需要重新启动后才会读取新值。

预设保存在 `%LOCALAPPDATA%\Alice-tower\TowerTools\dev.towertools.proxyenvmanager\proxy-presets.properties`。已有预设继续使用，升级或重新构建不会覆盖或清空用户配置。

测试使用模拟环境变量验证草稿、差异保存、冲突、失败恢复和真实 Compose 界面交互，不修改机器的代理设置。真实注册表集成测试仅在显式设置 `TOWER_RUN_PROXY_ENV_INTEGRATION=1` 时执行，并在结束后恢复原值。

## 从当前项目运行

```powershell
.\gradlew.bat run
```

## 发布便携目录

在仓库根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Tool.ps1 -Id "dev.towertools.proxyenvmanager"
```

发布后的应用位于：

```text
outputs/tools/dev.towertools.proxyenvmanager/
```

如需创建不发布到 `outputs/` 的项目本地 Compose application image，请运行：

```powershell
.\gradlew.bat createDistributable
```
