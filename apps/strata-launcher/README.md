# Strata 启动配置器

使用原生 Kotlin/JVM + Compose Desktop 界面浏览、启动和删除本地 Strata 预设，配置参数并生成终端命令。预设列表统一提供启动与管理操作，自定义启动页配置模型启动参数；两个页面均可预览、复制或打开终端执行当前命令。右上角显示本地 7271 端口的连通状态，并提供复制 API 地址和打开网页的入口。

- 项目：`StrataLauncher`
- Application ID：`dev.towertools.stratalauncher`
- 版本：`1.9.1`
- 作者：`Alice-tower`

## 使用

1. 从工具塔的“工具”页打开，或直接运行便携目录内的 `StrataLauncher.exe`。
2. 默认打开“预设列表”，左列“全部预设”上方的“全局操作”默认选中。选择全局操作或具体预设后，在右列选择相应操作，下方显示命令预览；右下角可复制或打开 CMD 执行。选中预设后，右侧操作区可打开 JSON 或选择红色“删除预设”。
3. 如需配置模型启动参数，在“自定义启动”填写参数。右下角“复制”（Ctrl+Enter）复制当前预览，“执行”打开 CMD 运行该命令。两个页面共用相同的底部预览栏；已有预设的参数可在预设操作区点击“打开 JSON”，交给系统默认程序编辑。

生成命令不要求安装 Strata；执行时需要本机已有可用的 `strata` 命令。工具不携带或安装 Strata、Python、推理引擎和模型。

自定义启动页带选项的输入框与选择框统一使用右侧向下箭头展开列表，量化版本支持手动输入。预设操作的目标由左列选中项决定。

## 端口状态与快捷入口

- 两个页面上方的右侧区域固定显示 `127.0.0.1:7271` 的状态，启动后立即检测，此后每两秒更新。连通显示绿点，未连通或初次检测中显示灰点；切换页面不中断检测，关闭窗口后停止。
- “复制 API”复制 OpenAI 兼容 API 的基础地址 `http://127.0.0.1:7271/v1`，不包含密钥，也不复制命令。
- “打开网页”使用系统默认浏览器打开 `http://127.0.0.1:7271`。未连通时两个按钮仍可使用。
- 此区域固定面向 7271 端口，不随自定义启动页填写的端口变化。状态只表示本机 TCP 端口可连接，不验证服务身份、鉴权或模型是否就绪；检测在后台执行，不阻塞界面。

## 两个工作页

### 预设列表

- 排在第一个且每次打开默认显示。左列列出当前目录中的预设名称，单击选中；右列显示当前分类适用的命令和文件操作。两列各自滚动，底部预览和按钮保持可见。错误文件显示文件名和原因，可选中后打开 JSON 修正，命令复制和执行保持禁用。
- 优先使用 `STRATA_LAUNCH_PRESET_DIR`；其次为 `STRATA_PROFILE_DIR` 的同级 `launch-presets`；否则使用 `%APPDATA%\Strata\launch-presets`。可选择其他目录、手动刷新或打开目录。
- 左列最上方为“全局操作”，每次打开默认选中，默认调用 `strata launch --status`，预览会在调用前附加当前预设目录的环境变量设置。此分类包含查看状态、列出预设、停止全部服务，统一使用文本输出；停止全部服务时不额外显示底部提示。
- 右侧“全局操作”容器底部固定提供“实验性设置”。对话框列出已安装的 `strata-*.json` 基础配置，每项显示配置中的 ESP 状态并提供“启用 ESP / 关闭 ESP”；此状态不代表运行中服务的实时状态。保存后需手动重启模型，不会自动加载、停止或重启服务。
- 基础配置优先使用 `STRATA_INSTALL_DIR`；否则读取 Strata 用户设置和 `app-settings.json` 中登记的安装目录，并包含 `%LOCALAPPDATA%\Strata\install`（支持 `STRATA_SETTINGS_FILE`、`STRATA_COMPONENTS_DIR`）。不会把启动预设、`.bak`、`.shared-settings.json` 当作基础配置。
- 启用时将标准 ESP 参数写入 `user_args`（强度 1.0、层范围 4–44、project/per-layer）；关闭时同时清除 `args` 与 `user_args` 中的 ESP 参数，避免旧配置重新启用。保留其他参数、密钥和未知字段；先备份、再原子替换，文件在界面读取后被外部修改时拒绝覆盖并提示刷新。备份位于本工具用户目录的 `esp-backups/`。
- 启用需要支持 `user_args` 的新版 Strata Terminal 及本地 ESP 向量文件；工具不会下载向量。默认查找 Terminal 的 `current/data/experimental-speed-projection/`，也可沿用配置中的向量位置。当前开关面向原版 Qwen3.8-Flash-Next / Coder；已有其他控制向量时不替换它们。
- 选择具体预设后，显示启动预设、停止该预设服务、查看密钥和删除预设。启动调用为 `strata launch --preset test`，预览同时包含当前预设目录的环境变量设置；除名称外不附加其他 Strata 参数。查看密钥会在终端显示结果。
- 全局操作和具体预设的操作各自限定范围，不会在停止选中预设时隐式停止全部服务。自定义启动页的参数不会影响此页。
- 选择操作只更新预览，不自动复制或执行。右下角“复制”（也可按 Ctrl+Enter）和“执行”使用同一条预览命令，统一面向 CMD。刷新、执行期间按钮禁用；选中项从刷新结果消失或文件变为无效时，命令不可执行。
- 预览与复制的命令以 `set "STRATA_LAUNCH_PRESET_DIR=当前目录" && ...` 指定目录，粘贴后仅改变当前 CMD 会话的环境变量。应用内执行将同一目录传给子进程，两种方式均不修改系统环境变量。CMD 保持打开，缺少 Strata 或执行失败时可在该窗口查看；界面的“已发送”不代表命令已执行成功。
- 选中具体预设后，“打开 JSON”固定在右侧容器最底部，不随上方操作内容滚动或移动，调用系统默认程序打开对应文件；格式损坏的预设也可选中并打开。打开失败会在界面提示。
- “删除预设”是操作列表最后一项，以红色标识。选择后预览包含当前目录设置及 `strata launch --delete-preset test` 调用的完整命令，可复制；点击“执行”并确认后，在终端交由 Strata 删除。工具不直接删除文件，也不在发送命令后提前移除列表项；待终端完成后点击“刷新”更新列表。删除不能撤销。


### 自定义启动

- 模型系列使用固定下拉选项；量化版本提供常用选项，也可以手动填写。实际支持范围由已安装的 Strata 决定。
- 可配置数据目录、上下文、图片理解、并发、KV 格式、显存预留、GPU、调优、访问范围、端口和密钥来源。推理 / 资源及访问范围的下拉框只提供具体选项，不包含“默认 / 自动”；访问范围默认选择“仅本机”。
- 密钥来源提供由 Strata 处理、生成新密钥、直接填写三种选择。
- 不再提供“启动行为 / 高级参数”区域，命令不附加后台运行、打开网页、仅预览计划、自动接受提示等行为参数，也不提供下载源、输出格式或自定义引擎参数。
- 可填写“保存预设名称”，生成带 `--save-preset` 的模型启动命令，执行后由 Strata 保存。
- 两个页面共用底部预览栏，标题、预览框高度、执行说明及右下角“复制”和“执行”的布局一致。统一生成 CMD 单行命令，长命令在预览框中自动折行显示，不再提供终端类型或多行选项。参数无效或正在发送命令时，两个按钮均禁用。
- 默认 UD-IQ4_XS、128K、INT8、关闭图片理解、单并发、端口 7271、显存预留 2048 MiB、跳过调优。数据目录默认留空，使用 Strata 自身规则；不会写死某台电脑的模型路径。本机地址预览显示在“服务 / 访问”区域。

## 会话与密钥

每次启动均打开默认的“预设列表”页。模型参数、预设选择、操作选择和自选预设目录仅在本次打开期间保留，关闭即丢弃，不保存本地界面状态。同一次打开期间切换工作页仍保留各页的输入。

不再读取或写入旧版 `drafts.json`；已有文件保持原样，不影响启动。界面不提供参数说明开关、方案导入导出、页面重置或帮助弹窗。预设列表仅从 Strata 原生 `strata.launch/1` JSON 读取名称，其他模型参数交由 Strata 使用。文件需为 UTF-8（支持 BOM），上限 128 KiB。

运行日志仍位于 `%LOCALAPPDATA%\Alice-tower\TowerTools\dev.towertools.stratalauncher\logs\`，不记录命令或参数值。

预设列表不会将 JSON 中的密钥或模型参数载入表单，启动时由 Strata 读取原文件。直接填写的密钥仅在本次打开期间保留，会显示在生成命令中，并随复制进入剪贴板及终端历史。

CMD 对无法可靠传递的双引号、百分号和感叹号会显示错误，需移除这些字符后再生成命令；预设目录也遵循此限制。完整命令会校验 CMD 的 8191 字符上限，包括复制时的目录设置及执行时的终端包装，超限时禁用复制和执行。两个页面固定使用 CMD。

## ESP 备份与恢复

关闭 ESP 时分别检查 `args` 和 `user_args`，保留被另一层覆盖的非 ESP 控制向量及其参数。如果 ESP 和其他向量共用同一参数组，工具拒绝修改，需手动编辑。参数变换独立于文件读写，拒绝时不会创建备份或改动配置。

恢复时先停止对应模型，并关闭其他可能写入基础配置的程序。在 `%LOCALAPPDATA%\Alice-tower\TowerTools\dev.towertools.stratalauncher\esp-backups\` 中按时间和原文件名找到修改前的备份，核对内容与目标安装目录；另存当前配置后，将备份复制回原基础配置路径并恢复原文件名，再刷新实验性设置并重启模型。备份可能含 API 密钥，请按原配置的权限保管；整份恢复也会还原备份之后的其他配置修改。

## 内部结构

`CommandResult` 保存命令参数、原始调用和环境变量，`CmdCommand` 统一生成可复制文本并校验长度；预览与执行共用这一计划。`EspArguments` 只负责单层参数变换，`EspConfigRepository` 负责发现、校验、备份与写入配置。1.9.1 的回归测试覆盖复制和执行的目录一致性、完整命令长度、被覆盖向量的保留、含混参数拒绝及备份内容。

## 范围

除本地 7271 端口连通状态和基础配置的 ESP 开关外，当前不提供服务详细状态监控、模型下载管理、硬件检测、显存估算或通用模型运行配置编辑。空闲卸载、按需加载、思考深度等应在 Strata 对应模型运行配置中编辑。
