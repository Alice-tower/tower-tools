# 工具塔

在“工具”Tab 中浏览和启动便携工具，在“CMD”Tab 中登记和启动本机 `.cmd` 项目和静态网页，在“仓库”Tab 中发现 Git 仓库。

- 项目：`TowerLauncher`
- Application ID：`dev.towertools.launcher`
- 版本：`1.4.33`
- 作者：`Alice-tower`

侧边栏的“收藏”和“全部”固定在最上方；其他分类可拖动左侧的 `≡` 调整顺序，松开后立即保存，并同步“全部工具”的分组顺序。启动时如果有收藏工具则默认显示收藏，否则显示全部。工具左侧的爱心可直接切换收藏状态：红色实心表示已收藏，灰色空心表示未收藏。操作立即生效；右键菜单中的“编辑”对话框可修改分类和工具在分类内的排序。工具排序仍决定列表顺序，但数字不显示在工具卡片上。

三个 Tab 使用相同的页头布局。工具页的“设置”对话框左侧纵向排列“打开启动器配置”和“打开工具配置”，分别在资源管理器中打开 `%LOCALAPPDATA%\Alice-tower\TowerLauncher\` 与 `%LOCALAPPDATA%\Alice-tower\TowerTools\`；打开目录后对话框保持显示，右下角“完成”负责关闭。各工具的分类和排序通过右键菜单编辑，右键菜单不再提供“查看日志”；切换 Tab 后筛选状态会保留。CMD 页读取和保存 `%LOCALAPPDATA%\Alice-tower\TowerLauncher\tabs\cmd\projects.properties`。“设置”将添加项目表单放在独立的圆角边框内，不列出已登记项目；添加成功后清空表单并保持设置页打开，右下角“完成”负责关闭。已有项目通过卡片右键“编辑”打开统一对话框，在“项目设置”页签编辑项目或删除登记。项目支持手动启动，并每 3 秒检测本地 Web 端口；端口检测仅在 CMD Tab 显示时运行。

CMD 页另将项目分类、分类顺序、分类内排序和收藏保存在同目录的 `appearance.properties`，按项目 ID 关联，编辑名称或启动文件路径后仍保留。侧栏的“收藏”和“全部”固定在顶部，其余分类可拖动 `≡` 排序；“全部”按分类分组。项目卡片左侧爱心可切换收藏，右键菜单的“编辑”对话框提供“分类和排序”“项目设置”两个页签，后者可修改项目名称、启动文件路径和 Web 端口，并通过“删除登记”按钮移除项目；删除前仍需确认。右键菜单另保留“打开所在目录”；双击卡片可启动项目。首次打开时若有收藏则显示“收藏”，否则显示“全部”；切换 Tab 后筛选保留。文件损坏时取消写入并显示错误，以保护现有数据。

三个 Tab 的列表卡片统一为 80 dp 高度，左侧收藏爱心使用相同的宽度与水平位置。双击工具或 CMD 条目可启动，双击仓库条目可打开该仓库目录；卡片不再显示对应的“启动”或“打开”按钮。CMD 的“打开浏览器”按钮仍用于访问项目 Web 端口。CMD 卡片在标题下显示启动文件完整路径；空间不足时按实际文字宽度计算，保留路径开头和文件名末尾，以省略号代替中间字符，不挤占右侧状态和浏览器按钮。仓库卡片有展示名称时，主标题显示展示名称、副标题显示目录名；没有展示名称时只显示目录名。卡片不显示详细路径，右键菜单可打开仓库的父目录。

三个 Tab 底部的默认反馈提示会分别说明双击条目的作用：工具页启动工具；CMD 页启动脚本或打开静态网页；仓库页打开仓库目录。CMD 的提示同时说明端口可连接不代表项目已运行；仓库页的提示同时说明右键“打开所在目录”会打开父目录。

三个 Tab 的分类菜单与条目菜单共用 Material 菜单组件，背景色、文字与悬停效果统一跟随明暗主题。分类右键选择“编辑”可修改名称。三个 Tab 的条目右键菜单均在点击的鼠标位置打开，靠近窗口边缘时自动调整位置；长按条目不触发操作。菜单统一为“打开所在目录”和“编辑”两项；仓库页的“打开所在目录”打开仓库的父目录，双击条目才打开仓库目录。CMD 的项目编辑与删除登记合入编辑对话框的“项目设置”页签；仓库的展示名称设置合入编辑对话框的“展示名称”页签。CMD、仓库编辑对话框的各页签单独保存，切换页签保留输入；点击“保存当前页”后显示保存结果并保持对话框打开，可继续编辑其他页签，点击“关闭”结束编辑。未保存的输入在关闭对话框后丢弃。卡片不显示“更多”按钮。

仓库页将扫描路径和最近一次扫描结果保存在 `%LOCALAPPDATA%\Alice-tower\TowerLauncher\tabs\repositories\locations.properties`。右上角“设置”对话框管理路径并显示每个路径的子目录数量、仓库数量和上次扫描时间；其左侧的“刷新”按钮会扫描所有已添加路径。扫描只检查各路径的直接子目录，忽略路径本身；只有包含 `.git` 目录的子目录会显示为 Git 仓库。重新打开启动器时显示上次结果，不自动扫描；移除路径只删除登记。

仓库页另将仓库分类、分类顺序、分类内排序、收藏、展示名称和“使用极简按钮”开关保存在同目录的 `appearance.properties`，与工具页设置互不影响。侧栏的“收藏”和“全部”固定在顶部，其余分类可拖动 `≡` 排序；“全部”按分类分组。仓库卡片左侧爱心可切换收藏；右侧的 README 和 AGENTS 按钮分别用系统默认程序打开仓库目录根部的 `README.md` 和 `AGENTS.md`，对应文件不存在时按钮置灰。卡片读取本地 `.git/config`，支持远端配置中的行尾注释和带引号的 URL；末端带 GitHub 图标的 GITHUB 按钮在识别到 GitHub 远端时可点击打开仓库网页，否则置灰。GITHUB 右侧带 VS Code 图标的按钮使用本机安装的 VS Code 在新窗口打开该仓库目录；点击时在后台查找 VS Code，未找到时显示如何配置 PATH 的错误提示。设置中勾选“使用极简按钮”后，仓库卡片右侧改为紧凑的 R、A、GitHub 图标和 VS Code 图标按钮；取消勾选恢复完整文字按钮。旧配置缺少此开关时默认使用完整按钮。读取远端配置失败时，仓库页底部显示原因，并将错误写入日志。常见 HTTPS、SSH 和 Git 协议的 `github.com` 地址会转换为 HTTPS 网页地址，不进行网络连通性验证。进入仓库页及手动刷新后会重新检查文件和远端。右键“编辑”可在“分类和排序”“展示名称”两个页签中修改对应设置，右键菜单另可打开仓库的父目录，双击卡片可打开仓库目录。展示名称留空并保存即可清除。首次打开时若有收藏则显示“收藏”，否则显示“全部”；切换 Tab 后筛选保留。设置以仓库完整路径识别，重新扫描或移除并重新添加相同路径不会丢失原有设置。文件损坏时取消写入并显示错误，以保护现有数据。

三个 Tab 的左侧具体分类（包括“未分类”）均可右键选择“编辑”，在对话框中修改分类名称并保存。首尾空格会自动去除，名称不能为空，也不能与已有分类重名；“收藏”和“全部”是固定筛选项，不提供改名菜单。保存会一次更新该分类内所有条目及分类顺序，保留条目排序、收藏和仓库展示名称；正在浏览的分类会跟随新名称继续显示。保存失败时对话框显示错误，保留原配置。

编辑条目的分类时可从分类输入框的下拉列表选择已有分类，也可直接输入新分类。

分类、分类顺序、工具排序和收藏保存时会先写入临时文件，再原子替换用户配置。现有配置无法读取时会取消保存，并在编辑对话框或列表底部显示错误，保留原文件。

启动器运行时始终显示系统托盘图标。托盘图标仍由 Windows 管理，右键菜单使用与启动器主界面相同的 Compose 文字绘制，支持中文与系统明暗主题；不额外打包字体。菜单采用紧凑行高和字号，跟随当前显示器的系统缩放；以窗口坐标读取鼠标位置，紧贴右键点击时的鼠标位置显示（间距 2 个逻辑像素），空间不足时向另一侧展开，仅限制在当前屏幕边界内，允许覆盖任务栏，点击菜单外或按 Esc 会收起。点击窗口关闭按钮或按 Alt+F4 只会隐藏窗口，保留当前 Tab、筛选和页面状态；后台仓库扫描可以继续。双击托盘图标，或右键选择“显示启动器”，即可恢复并聚焦原窗口；最小化时会恢复，最大化状态会保留。只有托盘右键菜单中的“退出”会结束启动器，并移除托盘图标、停止后台任务和释放单实例锁。重复启动也会恢复现有窗口；激活连接设有读超时，避免无响应连接长期阻塞。

窗口与 Windows 可执行文件使用仓库统一图标。
启动时以稳定 Application ID 登记 Windows 任务栏身份，避免任务栏显示 Compose 默认图标。便携目录中的 `app-icon.ico` 可作为桌面快捷方式的显式图标来源。

## 运行

```powershell
.\gradlew.bat run
```

## 构建便携目录

```powershell
.\gradlew.bat createDistributable
```

仓库生命周期脚本会将生成的 Windows application image 复制到共享的 `outputs/` 目录。

## 开发 Tab

Tab 由 `TabId` 枚举和 `Main.kt` 中的 `LauncherTab` 列表编译时注册。工具页、CMD 页和仓库页分别维护在 `tabs/tools`、`tabs/cmd`、`tabs/repositories` 包；新 Tab 也应有独立业务包、状态和用户数据。新 Tab 的数据目录统一位于 `%LOCALAPPDATA%\Alice-tower\TowerLauncher\tabs\<stable-key>\`。完整约定及交付步骤见 [启动器 Tab 开发规范](../../docs/launcher-tabs.md)。

CMD Tab 支持登记 .cmd、.html 和 .htm 文件（扩展名不区分大小写）。静态网页通过默认浏览器直接打开本地文件，不需要端口，也不会启动 HTTP 服务；依赖本地服务的网页仍需通过 CMD 脚本启动服务。已有项目配置保持兼容。
