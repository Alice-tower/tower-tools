# Tower Tools

Tower Tools 是使用 Kotlin/JVM 和 Compose Desktop 编写的 Windows x64 便携桌面工具箱。**工具塔**把独立 GUI 工具、本机 `.cmd` / `.bat` 项目、静态网页和 Git 仓库的入口集中到同一个窗口，分别由“工具”“CMD”“仓库”三个 Tab 管理。

## 快速开始

仓库不提交构建产物。首次从源码使用时，请在 Windows 10 或更新版本（x64）上准备 JDK 21（设置 `JAVA_HOME`）和 PowerShell 5.1 或更新版本，然后在仓库根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-All.ps1
```

首次构建需要联网下载依赖。构建完成后，运行 `outputs\launcher\TowerLauncher.exe`。`outputs/` 内含启动器、独立工具及各自的 Java 运行时；复制到另一台电脑时请保留整个目录结构，目标电脑无需另装 Java。完整构建要求见 [构建环境](docs/build-environment.md)。

工具塔关闭窗口后会保留系统托盘图标和页面状态。双击托盘图标或右键选择“显示启动器”恢复窗口；右键选择“退出”结束启动器。托盘菜单与主界面使用相同的中文绘制方式，采用紧凑布局并适配屏幕缩放，紧贴右键点击的鼠标位置弹出，点击外部或按 Esc 可收起菜单。

## 工具塔的三个 Tab

### 工具：启动便携应用

- 显示本仓库已构建的独立工具。双击条目启动工具；右键选择“编辑”可修改分类与排序，也可打开所在目录。
- 左侧可按“收藏”“全部”和自定义分类浏览；点爱心收藏，拖动分类手柄调整分组顺序。这里管理的是已打包工具，不负责安装或更新。

### CMD：登记常用脚本和静态网页

- 在“设置”中登记本机 `.cmd` / `.bat` 项目和静态网页；双击条目运行脚本或用默认浏览器打开静态网页。可按分类、排序和收藏整理，右键选择“编辑”后，可在“分类和排序”“项目设置”两个页签中修改设置或删除登记。
- CMD/BAT 脚本项目可选填本地 Web 端口，以查看端口是否可连接，并用“打开浏览器”访问项目页面。**端口可连接不等于该项目已运行。**

### 仓库：浏览本地 Git 仓库

- 在“设置”中添加扫描路径，再点击“刷新”。每条路径只扫描其**直接子目录**中含 `.git` 目录的仓库；重新打开启动器会显示上次结果，需要手动刷新才能更新列表。
- 双击仓库条目打开**仓库目录**；右键“打开所在目录”打开其**父目录**。右键选择“编辑”后，可在“分类和排序”“展示名称”两个页签中修改对应设置；收藏仍可直接切换。
- 条目右侧可打开根目录的 README、AGENTS、已识别的 GitHub 远端网页，或用本机 VS Code 打开仓库。对应文件或 GitHub 远端不存在时按钮置灰；“使用极简按钮”可在设置中开启。
- 右键“Git 状态”可查看当前分支、提交记录，以及已暂存、未暂存和未跟踪的文件路径。对话框顶部左侧显示仓库名称与路径，右侧集中显示分支、同步目标及远端更新状态；下方左侧显示最近 10 次提交，滚到底部可每次加载 10 条，左下角可打开当前仓库目录。右侧提供文件改动、远端和操作结果页签；文件改动顶部汇总三类文件数量，只列出有文件的类别。打开后先显示本地信息，再后台 Fetch 更新远端状态，并显示更新中、完成或失败及更新时间；可查看跟踪目标与领先／落后情况，使用只允许快进的 Pull 和仅推送当前分支的 Push。没有远端时两个按钮置灰；已有跟踪目标时沿用，否则自动使用 `origin` 上的同名分支，目标远端分支不存在则报错，不创建远端分支或设置跟踪关系。操作结果附带年月日和时分秒。此功能需要本机安装 Git for Windows，并配置对应远端的凭据。

三个 Tab 的具体分类均可在左侧右键选择“编辑”修改名称，分类内条目会同步更新，并保留分类顺序、条目排序和收藏。三个 Tab 的分类、收藏和排序互不影响。更多操作细节见 [工具塔说明](launcher/TowerLauncher/README.md)。

## 仓库中的独立工具

| 工具 | 用途 |
| --- | --- |
| [代理环境变量](apps/proxy-env-manager/README.md) | 查看和管理当前用户的 HTTP 代理环境变量。 |
| [图片裁剪与分割](apps/image-processor/README.md) | 旋转、裁剪和分割单张图片，预览后输出，不修改原图。 |
| [图片元数据解析器](apps/nai-box/README.md) | 本地查看图片元数据、AI 生成参数和角色卡内容。 |
| [影音转写](apps/media-transcriber/README.md) | 从媒体提取 MP3，使用自备的 FFmpeg、CUDA 版 Whisper 和模型转写音频。 |
| [本地资源语义管理器](apps/resource-tagger/README.md) | 扫描指定目录，以标签和别名整理资源并定位文件，不修改资源本身。 |
| [静读](apps/tower-reader/README.md) | 离线管理并阅读 TXT、EPUB、PDF，支持单双页、自动保存进度及内嵌微信读书网页版。 |

## 数据、文档与许可

分类、项目登记等用户设置保存在 `%LOCALAPPDATA%\Alice-tower\` 下；重新构建或替换便携程序不会覆盖这些数据。`outputs/` 已被 Git 忽略。

开发者可从 [独立工具生命周期](docs/tool-lifecycle.md)、[Tab 开发规范](docs/launcher-tabs.md)和[项目架构](docs/architecture.md)开始。仓库原创代码使用 [MIT 许可证](LICENSE)；打包组件的许可和来源见[第三方声明](THIRD_PARTY_NOTICES.md)。
